# 長文（読みもの）— 素材の作り方

級ごと・カテゴリごとの読みものを、この形で置く。実装側（表示・読み上げ・音読）は
この形を正本にする。

AI生成の月1本ストーリー（`generatedStories`）とは別物。あちらは本人の復習単語から
その場で作るもの、こちらは作り置き。

---

## 0. はじめに

**本文はオリジナルを書く。** 市販の問題集や過去問の英文には著作権がある。
級ごとの語数・文構造・話題の傾向に合わせるのは形式なので問題ない。

**語彙はその級までに収める。** 5級の長文に2級の語が混ざると、読めない語が
理由で止まる。`node scripts/checkReadings.js` がカバー率を測るので、
書いたら必ず通すこと。

---

## 1. 置き場所

```
public/reading/index.json          級とカテゴリと読みものの一覧
public/reading/{級}/{id}.json      読みもの1本
```

`{級}` は `5` / `4` / `3` / `pre2` / `2` / `pre1`。

---

## 2. データの形

```jsonc
{
  "id": "eiken5-daily-01",
  "grade": "5",
  "category": "daily",
  "title": "My Morning",        // 英語の見出し
  "titleJa": "わたしの朝",        // 一覧に出す日本語

  "sentences": [
    {
      // 文全体の自然な和訳。チャンクの和訳をつなげても日本語にならないので別に持つ。
      "ja": "わたしは毎朝6時に起きます。",

      // 文を意味のまとまりで割ったもの。スラッシュ読みとSVOCで同じ区切りを使う。
      // en をスペースでつなぐと元の文になる（文全体の en は持たない）。
      "chunks": [
        { "en": "I",              "ja": "わたしは", "role": "S" },
        { "en": "get up",         "ja": "起きます", "role": "V" },
        { "en": "at six",         "ja": "6時に",   "role": "M" },
        { "en": "every morning.", "ja": "毎朝",     "role": "M" }
      ]
    }
  ]
}
```

### chunks を1つにしている理由

スラッシュ読みの区切りとSVOCの区切りは、教える場面が違うだけで切り方はほぼ同じ。
別々に持つと、片方だけ直したときにズレても画面は普通に動いてしまい、
気づけない。1つの区切りに `role` を付けて、見せ方だけ変える。

### role

| role | 意味 |
|---|---|
| `S` | 主語 |
| `V` | 動詞 |
| `O` | 目的語（SVOOなら2つ並べる） |
| `C` | 補語 |
| `M` | 修飾語（副詞句・前置詞句・接続詞など、上のどれでもないもの） |

## 3. 級ごとの目安

| | 5級 | 4級 | 3級 | 準2級 | 2級 |
|---|---|---|---|---|---|
| 語数 | 40〜60 | 60〜80 | 80〜110 | 110〜150 | 150〜200 |
| 1文の語数 | 5〜9 | 7〜12 | 8〜14 | 10〜18 | 12〜22 |
| 時制 | 現在形が主 | 現在＋過去 | ＋現在完了 | ＋受動態・関係詞 | ＋分詞構文・仮定法 |
| 話題 | 身のまわり | 学校・家族 | 地域・行事 | 社会のしくみ | 社会問題・科学 |

---

## 4. 書いたら通すこと

```bash
node scripts/checkReadings.js
```

見るもの:

- `chunks` の `en` をつないで文になるか（二重スペース・空チャンクが無いか）
- `role` が S/V/O/C/M のどれかか
- **その級までの単語で何割書けているか**（固有名詞と基本的な機能語は除く）
- 語数が §3 の目安に収まっているか
- `index.json` と実ファイルが食い違っていないか
